# RAGelit v0.1.0-preview.1

MVP preview for local synthetic-data evaluation, not stable v0.1.
Tested application revision: `1ac8deb598b160393efed0fa4006b31ab1438afe`.

## Release notes

RAGelit is a multi-tenant document assistant with permission-aware hybrid search
and automated access-control auditing. This preview is for local evaluation with
synthetic documents, not confidential data or production deployment.

The portal supports document upload and indexing, organization roles,
user/group document grants, cited chat responses and scoped traces. Synthetic
audits export redacted JSON and offline HTML; the CLI also compares isolation
strategies and tests document-instruction attacks.

Start with the [quick start](../../README.md#quick-start), then follow the
[document workflow](../../README.md#try-the-document-workflow) or the
[synthetic audit demo](../../OPERATIONS.md#synthetic-access-control-cli).
Generation is disabled by default; configure a compatible endpoint for genuine
model answers. Screenshots and CI chat results use fixture generation, not a real LLM.

[PR CI](https://github.com/HuzaifaAbdulRehman/ragelit/actions/runs/37966718759)
passed 794 unit tests, 260 integration tests with four model-dependent skips,
and 57 browser journeys. All three validated audit export sets were uploaded.
The [post-merge run](https://github.com/HuzaifaAbdulRehman/ragelit/actions/runs/37972884533)
also passed at the tested application revision. Publication changes documentation
only; application code, service recipes and dependency locks are unchanged.

High/critical container findings remain unresolved. The 87-query CPU baseline
timed out on every generation request; answer quality and real-model injection
resistance are unverified. This preview does not close issues
[#23](https://github.com/HuzaifaAbdulRehman/ragelit/issues/23) or
[#24](https://github.com/HuzaifaAbdulRehman/ragelit/issues/24).
See the [checkpoint](../verification/2026-10-07-local-release-checkpoint.md)
and [container review](../security/2026-10-08-container-triage.md).
Do not attach old database volumes directly to the new images;
read the [upgrade warnings](../../OPERATIONS.md#existing-qdrant-data).

## Scope

This is a prerelease, not a production-security sign-off or completed benchmark.
It does not deploy services or migrate existing data. Model weights, credentials
and local benchmark artifacts are not included.
